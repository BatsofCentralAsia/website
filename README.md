# Bats of Central Asia — версия на чистом HTML

Без сборки: файлы публикуются как есть. Открыть локально — двойной щелчок по `index.html`.

## Структура

```
index.html                 стартовая страница (в каждой языковой папке своя)
help.html, myths.html, …   контентные страницы, русская версия (по умолчанию, корень сайта)
en/, uz/                   другие языки — те же файлы по тем же путям
encyclopedia/*.html        страницы видов и убежищ (в каждой языковой папке)
css/base.css               общая основа ночной темы: палитра, шрифты, соцсети, поиск, языки, подвал с пейзажем
css/start.css              стартовая страница
css/page.css               контентные страницы: шапка с меню, все компоненты
js/start.js                стартовая страница: поиск и переключатель языков
js/site.js                 контентные страницы: шапка, меню, языки, подвал, мифы, фильтры видов
images/                    логотип, фото, пейзаж для подвала (landscape.jpg)
```


В `js/site.js` также настраиваются ссылки на соцсети (`SOCIAL`); на стартовых страницах они прописаны прямо в `index.html`. Поиск пока открывает Google с `site:<домен>` — заработает после публикации.

## Правила

- Перевод страницы лежит **по тому же пути** в папке своего языка: `help.html` ↔ `en/help.html` ↔ `uz/help.html`. На этом построен переключатель языков.
- В `<html>` каждой страницы есть `lang`, `data-root` (путь до корня: `""`, `../`, `../../`) и `data-path` (путь внутри языковой папки). Новую страницу проще всего сделать копией похожей.
- Все ссылки относительные — сайт работает на любом домене и в подпапке GitHub Pages.

## Как добавить…

- **пункт меню** — в `NAV` и в `T.<язык>.nav` в `js/site.js`;
- **вид** — скопировать страницу вида (например, `encyclopedia/pipistrellus-kuhlii.html`) во все языковые папки и поправить текст; затем скопировать карточку `<article class="species-card">` в `encyclopedia/species.html` каждого языка. Атрибуты карточки управляют фильтрами: `data-countries` (коды стран через пробел), `data-redbook` (страны, где вид в Красной книге), `data-wind` (`high` / `medium` / `low`), `data-search` (слова для поиска);
- **язык** — папка `xx/` с копиями всех страниц (`lang="xx"`, `data-root` на уровень глубже), плюс запись в `LANGS` и `T` в `js/site.js`.

## Публикация

GitHub Pages → Settings → Pages → Deploy from a branch → `main` / корень. (Содержимое этой папки должно лежать в корне репозитория.) Домен — файл `CNAME` в корне.
